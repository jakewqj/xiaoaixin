# art-src · 美术源文件(不进构建)

这里放**生成精灵之前的原始素材**:ChatGPT / Gemini 出的整图、打包的 zip、
手绘扫描件。它们是画精灵时的参考,游戏运行时一个字节都不读。

## 为什么不放 `public/`

`public/` 里的任何文件都会**原样进 `dist/` 并对外可访问**(CLAUDE.md
「三、技术约束 · 部署 · Vercel 踩过的坑 ⑤」)。这批图共 17MB,一直跟着
每次部署发到线上,童童那边白等加载,而且是公开可下载的。

2026-09-18 从 `public/assets/npc/` 挪到这里。**只挪位置,零代码改动** ——
`npc.json` 里没有任何一条 `精灵` / `头像` 指向它们,挪之前逐个 grep 确认过。

## 往这儿加东西的规矩

- 游戏要读的图 → `public/assets/`
- 画图时参考的图 → `art-src/`
- 判据只有一条:**运行时有没有代码按路径去取它**
