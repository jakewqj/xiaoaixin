| # | 决定 | 理由 |

| 1 | **三海域用"海龟信使 + 想象远行"串联** | 真实儒艮游不到澳洲。直接切换等于给童童第一个假知识。诚实标注反而制造了一次提问机会 |

## 1. 设计基石

### 1.1 五条继承原则

1. **没有失败态** —— 不会死、不会生病、不会因为你没来而衰弱
2. **文字是奖励，不是门槛** —— 读不懂也能靠图标玩下去
3. **不打扰** —— 无推送、无签到、无连续天数清零
4. **小爱心不是老师** —— 无分数、无对错音效差异、无测验界面
5. **知识走白名单** —— 所有事实人工核对，不知道就说"我们去问爸爸"

### 1.2 五条新增原则

**原则 6：世界会变化，但变化永远可逆、永远不惩罚。**

牧场物语靠"作物枯萎、动物生病"制造压力。星露谷的好感度会衰减。这套机制对成年人有效，对 6 岁是纯粹的焦虑源。

- 海草床没人管 → 长得慢、水浑一点，**不会死光**
- 朋友很久没见 → 第一句是"你去哪儿了呀"，**熟悉度只增不减**

**原则 7：野生动物不被拥有。**

牧场物语可以圈养鸡和牛，我们不能。所有 NPC 都是**自由的邻居**，不是宠物、不是资源。没有捕捉、饲养、繁殖机制。这条会自然长出正确的价值观，不需要说教。

**原则 8：语言是角色的属性，不是玩家的任务。**

修订自旧宪法第九条（原为"英语只做同一件事的第二种叫法，禁止英语学习模块"）。

三条底线守住，就不会滑向英语关卡：

- ❌ 无单词卡、无发音评分、无正确率
- ❌ 不需要键盘打字，全部是**图标 + 英文短句选项**，点击朗读
- ✅ 选"错"了，对方只是歪歪头再说一遍，**音效完全一样**

**原则 9：所有生物与场景细节必须有真实出处。**

每个 NPC、每种海草、每个自然事件，都要能在 `content/facts.json` 指到一条已核对的来源。编出来的"可爱设定"一律不要——理由和白名单一样，她会全信。

**原则 10：她画的、写的，永远不被判对错，永远不消失。**

- ❌ **不做手写识别**（识别失败 = 挫败，且对儿童字迹几乎必然失败）
- ❌ 不打分、不纠正、不"再写一次"
- ✅ 笔迹原样存图，永久留在世界里，能反复看到

## 2. 核心循环

```
        ┌──────────────────────────────────────┐
        │                                      │
   [照料家海草床] → [海水变清 / 海草长成]        │
        │                                      │
        ↓                                      │
   [带着海草出门] → [遇见邻居] → [对话 / 送礼 / 交易 / 送画]
        │                                      │
        ↓                                      │
   [熟悉度提升] → [解锁小故事 + 图鉴卡]          │
        │                                      │
        ↓                                      │
   [小爱心长大] → [解锁新地点 / 新海域] ──────────┘
```

**一句话**：养的是一片海，小爱心是入口，邻居是内容。

**单次游玩（8–15 分钟）**：开场问候 → 换气 1–2 次 → 看今日成长 → 打理海草床 → 出门遇见 1–2 个邻居 → 互动 → 回家睡觉存档。

**不设每日必做清单。** 任何一步都可以跳过。

## 3. 世界观：远行叙事

### 问题

真实儒艮终生活动在近岸浅海，最长移动记录也就几百公里。**它不可能从红海游到波斯湾再到澳洲。**

### 方案：海龟信使 + 想象远行

**真实依据**：绿海龟和蠵龟是真正的跨洋洄游者，会游几千公里回到出生地产卵。

> 有三只海龟，一辈子都在大洋里绕圈。
> 它们每年会路过小爱心的家，带来远方的消息。
> 小爱心听着听着，就在午睡时"游"到了那里。

| 信使 | 来自 | 解锁 | 性格 |
|---|---|---|---|
| **绿绿**（绿海龟） | 红海本地 | 一开始就在 | 话痨，什么都讲一遍 |
| **老蠵**（蠵龟） | 印度洋 | 少年期 | 沉默，一次只说一句，但那句很重 |
| **玳玳**（玳瑁） | 太平洋 | 亚成年 | 好奇，专门问问题 |

### 诚实标注（不可删改）

进入远行海域时，加载画面固定显示：

> 🐢 真的儒艮不会游这么远。这是小爱心的想象。

**这行字不许删、不许改、不许配置关闭。** 童童问"为什么它不能游过去"的那一刻，比整个游戏值钱。

## 4. 场景系统

### 4.1 三级结构

```
海域（World）        3 个
  └ 地点（Spot）      每海域 4–6 个
      └ 互动点        每地点 3–8 个
```

### 4.2 红海浅滩（家 · S1–S3）

原型：埃及马沙阿拉姆、阿布达巴布湾

| 地点 | 内容 | 常驻邻居 | 学习挂载 |
|---|---|---|---|
| **家海草床** | 种植、收割、水质变化 | — | 数学（计数、分配）、生物 |
| **换气水面** | 抬头看天、云、星星 | 海鸟 | 自然（昼夜、天气） |
| **海豚潟湖** | 白天海豚在这里休息 | Dolly | **英语主战场**、数学 |
| **珊瑚花园** | 五颜六色的珊瑚、小鱼群 | 小丑鱼一家 | 自然（颜色/共生）、英语 |
| **沙地浅滩** | 挖沙、找贝壳 | 砗磲奶奶 | 财商、历史 |
| **老沉船**（少年期） | 长满珊瑚的旧船 | 阿玳 | 历史、百科 |

**真实性**：
- 海草物种：*Halodule uninervis*、*Halophila ovalis*、*Halophila stipulacea*
- 红海海草床局限于 sharm / marsa（内湾）等浅水软底区
- 红海有 300+ 种珊瑚、2100+ 种鱼，约 10% 为特有种

### 4.3 印度海湾（S6）

原型：阿联酋马拉瓦海洋生物圈保护区、巴林–卡塔尔间的萨勒瓦湾

| 地点 | 内容 | 常驻邻居 | 学习挂载 |
|---|---|---|---|
| **红树林边** | 涨落潮变化最明显 | 招潮蟹兄妹、火烈鸟 | 自然（潮汐）、数学（对称） |
| **珍珠滩** | 珍珠贝床 | 珍珠爷爷 | **财商主战场**、历史 |
| **咸水浅湾** | 水特别咸、特别浅 | 驼背豚 Sousa | 自然（盐度/蒸发） |
| **越冬聚集地**（冬季） | 上百头儒艮聚成大群 | 儒艮群 | 生物、数学（估数） |
| **沉没的贝壳堆** | 古人采珠留下的贝丘 | — | 历史（人与海的关系） |

**真实性**：
- 近乎封闭的浅海，平均水深仅 35 米，只通过霍尔木兹海峡与外海相连
- 极端高盐 + 大温差，**只有 3 种海草能活**（*Halodule uninervis* 占 60%+）
- 全球第二大儒艮种群，约 5800–7300 头
- 冬季确有大群聚集记录（巴林–卡塔尔间曾目击 577 头一群）
- 珍珠贝 *Pinctada radiata* 与采珠文化真实存在，考古贝丘可考

### 4.4 澳洲浅海（S7）

原型：西澳鲨鱼湾（Shark Bay / Gathaagudu）

| 地点 | 内容 | 常驻邻居 | 学习挂载 |
|---|---|---|---|
| **乌拉梅尔草原** | 全球最大海草床 | 儒艮大婶 | 生物、数学（大数） |
| **叠层石浅滩** | 地球最古老的生命 | 石头爷爷 | **历史/时间尺度主战场** |
| **海豚湾** | 会用海绵护鼻的海豚 | Sponge | 英语、工程思维 |
| **贝壳海滩** | 整片沙滩全是贝壳 | — | 自然（地质）、数学 |
| **深水通道**（成年期） | 光线变暗的地方 | 老虎（虎鲨） | 生物（食物链）、边界感 |

**真实性**：
- 海草床 4800 km²，12 种海草，世界最大最丰富之一
- 儒艮种群约 10000–11000 头，占全球约 1/8
- 叠层石由蓝藻形成，地球最古老的生命形式之一
- 高蒸发形成近两倍海水盐度，沿岸有全部由贝壳组成的海滩
- 莫基米亚野生宽吻海豚 50 多年来主动靠岸与人互动
- 鲨鱼湾海豚会用海绵包住吻部在海底觅食（真实的工具使用）
- 栖息 28 种鲨鱼，虎鲨为顶级捕食者

## 5. 成长系统

### 5.1 真实生活史映射

| 阶段 | 真实体长 | 累计游玩日 | 解锁 |
|---|---|---|---|
| **幼年 Calf** | 1.1–1.2 m | 1–14 | 家海草床、换气水面、珊瑚花园 |
| **少年 Juvenile** | 1.5–2.0 m | 15–40 | 红海全开 + 海豚潟湖 + 老沉船 |
| **亚成年 Subadult** | 2.2–2.6 m | 41–80 | 印度海湾 |
| **成年 Adult** | 约 3 m / 400 kg | 81+ | 澳洲浅海 + 雄性长出小獠牙 |

> 用**累计游玩日**而非自然日。三天没来，进度不会掉。

### 5.2 每日成长面板

```
┌─────────────────────────┐
│   今天的小爱心            │
│                         │
│   身长  ▮▮▮▮▮▯▯▯  1.4 m │
│   体重  ▮▮▮▮▯▯▯▯   68 kg│
│                         │
│   比昨天长了  1 厘米 📏   │
│   比上周重了  0.4 公斤    │
│                         │
│   [看看去年的我]          │
└─────────────────────────┘
```

**数学挂载**：厘米/米、公斤、加减、增长、"比…多"、折线图雏形
**关键**：数字每天都有变化，哪怕 0.1。**变化本身就是奖励。**

### 5.3 阶段跃迁的仪式

1. 小爱心自己发现"我好像变大了"
2. 一位老朋友评论一句（"你比我第一次见你高了这么多"）
3. 信使海龟带来新海域的消息
4. 图鉴新增一页
5. 相册自动生成"成长对比图"（可截图发给爷爷奶奶）

## 6. NPC 系统

### 6.1 通用规则

- **每个 NPC 都是真实存在的物种**，且真实分布在它所在的海域
- 属性：语言、性格、喜好、话题库、专属知识领域
- **熟悉度 5 级**：陌生 → 认识 → 熟悉 → 朋友 → 老朋友，**只增不减**
- 每升一级解锁：小故事 + 图鉴卡 + 新话题
- 送礼两档反馈：**很喜欢 / 谢谢你**，**没有"讨厌"**

### 6.2 红海

#### ⭐ Dolly · 旋转海豚（首发朋友）

| 项 | 内容 |
|---|---|
| 物种 | 旋转海豚 *Stenella longirostris*（红海潟湖白天休息，真实） |
| 语言 | **只说英语** |
| 性格 | 语速快、爱跳、坐不住 |
| 喜好 | 会动的东西、亮的东西、比赛 |
| 不感兴趣 | 石头、贝壳（"太慢了"） |
| 话题 | 数数、快慢、谁跳得高、今天天气 |
| 教育挂载 | **英语 + 数学（计数、比大小、速度）** |
| 词汇 | Hello / Let's go / One,two,three / Big / Small / Fast / Look! / Thank you |

```
Dolly:  "Hello! Look at me!"
        [🐬 Hello!]  [👀 Wow!]  [🌱 给它海草]

Dolly:  "One... two... three! Jump!"
        [🔢 Four!]  [👏 拍手]  [❓ ...?]

（选任何一个 Dolly 都会开心地转一圈。选 ❓ 时它放慢重说一遍。）
```

**所有英文短句点击后有朗读。童童靠听，不靠读。**

#### 绿绿 · 绿海龟（信使）
中文 / 话痨 / 地理·洄游·百科 / 信使系统入口 + 每周一条远方消息

#### 小金 · 幼年金鲹（跟班）
**真实依据**：幼年金鲹会跟着儒艮、鲨鱼、石斑鱼游动以求庇护。
**复读**——你说什么它说什么（中英都会）。这是童童练发音的安全出口，因为对方本来就只会重复。

#### 阿玳 · 玳瑁海龟
中文 / 慢 / 长句 / 讲故事的人 / 历史·百科（美人鱼传说、人与海的故事）

#### 砗磲奶奶 · 巨砗磲
**真实依据**：*Tridacna maxima* 是红海珊瑚礁常见物种。
不动 / 最年长 / 一次只说一句 / **图鉴总入口**。她就是白名单知识库的具身化，不知道的就说"这个我也不知道，去问爸爸"。

#### 小丑鱼一家 · *Amphiprion bicinctus*（红海特有种）
中文短句 / 很吵 / 家庭·共生·颜色 / 一家好几只，是**数数**的天然素材

### 6.3 印度海湾

#### ⭐ 珍珠爷爷 · 珍珠贝（财商核心）

物种 *Pinctada radiata*，阿拉伯湾真实珍珠贝，采珠文化根源。中文，慢，爱讲"以前"。

他教四件事：

1. **不是所有东西都一样值钱** —— 沙子到处都是，珍珠很少
2. **好东西要等** —— 一颗珍珠要长很多年
3. **换东西要两边都愿意** —— 交易不是抢
4. **有些东西不换** —— 朋友送的贝壳，卖了就没了

> 第 4 条是最重要的一条。财商教育最容易滑向"什么都能标价"，这条是解药。

#### 驼背豚 Sousa · 印度洋驼背豚
**真实依据**：南阿拉伯湾约 700 头。英语，但**说得慢、词更长**（对比 Dolly 的短促）。稳重、害羞。英语进阶（完整句子）。

#### 招潮蟹兄妹
中文 / 抢话 / **数学（对称与不对称）**——雄蟹一大一小两只螯，绝佳教具。退潮时出现在红树林边。

#### 火烈鸟
**真实依据**：波斯湾有大红鹳分布。中文。**"我的颜色是吃出来的"**（食物中的类胡萝卜素）。这条知识 6 岁听了会记一辈子。

### 6.4 澳洲浅海

#### ⭐ 石头爷爷 · 叠层石
**真实依据**：鲨鱼湾叠层石由蓝藻形成，地球最古老的生命形式之一。
中文，极慢，**每天只说一句话**。
这是全游戏唯一有此限制的 NPC——**这个限制本身就是在教"很久很久"是什么意思**，不要绕过它。

#### Sponge · 宽吻海豚
**真实依据**：鲨鱼湾海豚会用海绵护住吻部在海底觅食。
英语 / **工程·创造思维**——"我发明了一个办法"。可学会并带回红海用。

#### 儒艮大婶 · 同类
**真实依据**：鲨鱼湾儒艮有时聚成超过百头的大群。
中文 / **社会性**——小爱心第一次见到"很多和我一样的"。
**这是全游戏的情感高点，留到成年期，慢一点，别赶。**

## 7. 老虎 · 虎鲨（专章）

### 7.1 定位：他不是反派，也不是朋友

牧场物语里每个村民最终都能变成朋友。**老虎是这个游戏里唯一一个永远不会成为朋友的角色。**

这不是缺陷，这是他存在的全部意义。

> 童童迟早要知道：世界上有一些人，你不会和他成为朋友，但他也不是坏人。
> 你要做的是**保持距离、互相尊重、不必害怕**。

### 7.2 角色卡

| 项 | 内容 |
|---|---|
| 名字 | **老虎**（直白，不拟人化、不起可爱名字） |
| 物种 | 虎鲨 *Galeocerdo cuvier* |
| 出现地 | 澳洲浅海 · 深水通道边缘 |
| 出现条件 | 白天，只在通道口 20% 区域内。**从不进入海草床、从不靠近家** |
| 语言 | 中文，**每句不超过 6 个字** |
| 性格 | 平静、坦白、不解释 |
| 关系轴 | **距离**，不是熟悉度 |
| 教育挂载 | 生物（食物链）、自然（顶级捕食者的生态作用）、社会（边界感） |

**真实依据**：鲨鱼湾栖息 28 种鲨鱼，虎鲨为顶级捕食者；儒艮与海龟确实会因虎鲨存在而回避某些觅食区域，这一"恐惧地景"现象是鲨鱼湾生态研究的核心课题之一。

### 7.3 台词库（总共不超过 15 句，全是陈述句）

```
初次相遇：
  「我在这边。」  「你在那边。」  「这样就好。」

再次相遇：
  「你又来了。」
  「今天海水很清。」
  「我不饿的时候，什么都不做。」

被问"你吃什么"：
  「我吃海里的东西。」
  「有时候也包括你的同类。」
  「我不骗你。」

儒艮大婶在场：
  大婶：「我们不过去。」
  老虎：「对。」

靠得太近：
  「够近了。」
  （然后转身游走，不追、不叫、不加速）
```

**「我不骗你」是整个角色的支点。** 他是全游戏唯一一个会说出不好听的实话的角色。

### 7.4 「距离」机制

```
   小爱心                                    老虎
     ▲                                        ▲
     │────────────────────●───────────────────│
                          ↑
                      当前距离

     [靠近一点]   [就在这里]   [退回去]
```

| 级 | 状态 | 解锁 |
|---|---|---|
| 1 | 远远看见 | 图鉴卡「虎鲨」 |
| 2 | 他知道你在 | 台词库开启 |
| 3 | **互相知道**（上限） | 最后三句台词 + 图鉴卡「谁吃谁」 |
| 4 | 朋友 | **永久锁定**，点击显示「他不会。」 |

那个永远点不开的第 4 级，是这个设计里最好的一部分。

### 7.5 安全护栏（写死在代码里，不可配置）

- ❌ **永不追逐**。移动速度恒定，方向永远是远离玩家
- ❌ **永不扣任何数值**。无伤害、无惊吓值、无掉落
- ❌ **永不发出突然音效**。无低频嗡鸣、无鼓点、无音乐变调
- ❌ **永不出现牙齿特写、张嘴、血、追逐镜头**
- ❌ **永不在夜间出现**
- ❌ **永不"偶遇"**。必须玩家主动前往深水通道
- ✅ **随时可退**。点「退回去」立即回安全水域，无过渡动画
- ✅ 后台 `"虎鲨": false` 一键让他完全不存在，**默认关闭**

### 7.6 三张图鉴卡

| 卡 | childText | dadNote |
|---|---|---|
| **虎鲨** | 「他是这片海\n最大的猎手」 | 虎鲨是鲨鱼湾顶级捕食者，鲨鱼湾共 28 种鲨鱼 |
| **谁吃谁** | 「海草喂饱我\n我喂饱谁呢」 | 食物链。建议你在场时一起看，她大概率会追问。**诚实回答，不要说"虎鲨不吃儒艮"** |
| **不去的地方** | 「有些地方\n我们不去」 | "恐惧地景"：捕食者不需要真的吃掉猎物，光是存在就改变了猎物的分布 |

## 8. 互动系统

### 8.1 对话

- **话题库按熟悉度解锁**——朋友级会聊私事
- **语言按 NPC 属性切换**——英语 NPC 的选项全是英文短句 + 图标 + 朗读
- **每日一句**——每个 NPC 每天有一句和天气/潮汐/季节相关的话

### 8.2 送礼

每天每个 NPC 可送 1 次。反馈两档：**很喜欢 / 谢谢你**。熟悉度 +1（只增不减）。

### 8.3 Pencil 手写与绘画

#### ⭐ 画画送礼（最高优先级）

```
┌─────────────────────────┐
│  画点什么送给 Dolly       │
│   ┌───────────────┐     │
│   │   （画布）      │     │
│   └───────────────┘     │
│  🖍 颜色  ↩ 撤销  🗑 重来  │
│        [ 送给它 ]        │
└─────────────────────────┘
```

**关键在送出之后**：

- Dolly 收下并**挂在自己身边**
- 之后每次去潟湖，那张画都在
- Dolly 偶尔提起：「你画的那个，我很喜欢。」
- 每个 NPC 最多挂 3 张，满了说「我换一张挂，旧的收好了」（存进相册，不删除）

> 价值在于：**她的作品变成了世界的一部分，而不是一个被夸奖的结果。**
> 别加"Dolly 给这幅画打 5 星"。夸奖是廉价的，"它一直挂在那儿"不是。

#### 手写命名

| 可命名对象 | 时机 |
|---|---|
| 家海草床的每一片 | 种下时 |
| 新发现的地点 | 首次抵达 |
| 一颗特别的珍珠 | 获得时 |
| 每一次自然事件 | 事件结束后 |

手写在小纸条上 → 原样贴在那个地方，**永久显示她的笔迹**。
一年后她看到自己 6 岁写的字，那个价值不用解释。

#### 图鉴手绘页

每张卡左半留空白，可点「我来画」。不画也能看知识。
显示「你画了 N 张」——**不做进度条、不做完成度百分比**。

#### 给信使写信

绿绿每周带消息时可写回信，手写或画画均可。绿绿下周说「我送到了」。信件存进相册。**不需要真的送到任何地方**，这点不必解释。

#### 英语描红（默认关闭）

Dolly 说完英文后可出现淡灰色描字底，愿意就描，不愿意就跳过。

- ❌ 不判断像不像、不出现"再试一次"、永远有 [跳过]
- ✅ 描完 Dolly 说 "Nice!"，跳过 Dolly 也说 "Nice!"
- ✅ 后台 `"英语描红": false`，**默认关**

> 这是唯一一个可能滑向"学习模块"的功能。默认关，观察一段时间再决定。

### 8.4 交易与财商

#### 货币：贝币 🐚
真实依据：贝壳在人类历史上真实作为货币使用过（宝螺）。这本身就是一张历史卡。

#### 三个罐子（Spend / Save / Share）

```
┌──────────────────────────────┐
│  🐚 我的贝壳                   │
│  🛍 要花的     12             │
│  🏦 存起来      8             │
│  🎁 送朋友      3             │
│        [ 换一换 ]             │
└──────────────────────────────┘
```

- 挖到贝壳时童童**自己决定**放进哪个罐子
- 「存起来」满 20 个可换平时换不到的东西（延迟满足）
- **罐子之间不能互相挪动**——这是这个机制的全部意义
- 「送朋友」只能用来买礼物送 NPC

#### 交易规则
明码标价，**价格永不波动**。有些东西标 🚫「这个不换」（朋友送的、童童画的、图鉴、相册）。

#### 明确不做
❌ 讨价还价 ❌ 价格波动 ❌ 囤货牟利 ❌ 债务借贷利息 ❌ 破产负数

### 8.5 委托

每天最多 1 条，出现在绿绿那里。例："Dolly 想看五颜六色的东西"→ 带 3 个不同颜色的贝壳。
**无时限、无失败**，不做就一直挂着。完成给熟悉度 + 图鉴卡 + 几枚贝币。

## 9. 时间与自然事件

海洋没有明显四季，但有更真实、更有教育价值的东西。

### 9.1 每日：潮汐
跟随真实系统时间，一天两次涨落。
**真实知识点：潮汐每天晚约 50 分钟**（因为月亮）。
退潮时红树林、沙地浅滩露出更多东西；涨潮时能游到平时去不了的地方。

### 9.2 每月：月相
满月 → 大潮，浅滩通道打开。新月 → 小潮，星星最亮。

### 9.3 事件日历（我们的"节日"）

| 事件 | 触发 | 海域 | 内容 | 真实依据 |
|---|---|---|---|---|
| **珊瑚产卵夜** | 满月后 | 红海 | 整片珊瑚同时释放卵，像下雪 | 珊瑚集体产卵与月相相关 |
| **海龟孵化夜** | 夏季某夜 | 红海/澳洲 | 小海龟朝月光爬向大海 | 绿海龟/蠵龟产卵孵化 |
| **儒艮大集会** | 冬季 | 印度海湾 | 上百头儒艮聚成一群 | 巴林–卡塔尔间曾目击 577 头一群 |
| **鲸鱼路过** | 迁徙季 | 澳洲 | 座头鲸经过，只能远远看 | 座头鲸以鲨鱼湾为迁徙中转站 |
| **冬潮通道** | 冬季 | 红海 | 海平面上升，露出新通道 | 中部红海冬季海平面季节性上升 |
| **海草变少了** | 罕见 | 澳洲 | 海草枯了一片，大家一起补种 | 2011 年鲨鱼湾海洋热浪 |

**「海草变少了」的处理要小心**：
- **可修复**，只要童童参与就一定能修好
- **不会因为她不管而恶化**
- 不出现"死亡""灭绝"字眼
- 修复后小爱心说：「又长回来了。」
- 全游戏唯一一次触碰气候变化，**一次就够**

## 11. 控制后台

### 11.1 定位
不是运营后台，是**爸爸的调节旋钮**。目的：控制世界一次只对童童打开一点点。

### 11.2 双通道
- **通道 A**：`content/config.json`（直接改文件，重新部署生效）
- **通道 B**：隐藏爸爸页（长按标题 5 秒 + 4 位数字密码，改动存 localStorage 覆盖 A）

完整 schema 见 `content/config.json`。

### 11.3 除配置外必须有的两样

**1. 对话日志导出**
导出童童和所有 NPC 的对话记录为 txt。不是监控，是让你知道**她在哪一句上反复点、在哪个 NPC 那里待最久**。这个数据决定下个 Season 做什么。

**2. 一键"回到只有小爱心"**
关掉所有邻居和系统，回到最初那片海。**这个开关必须存在**——内容膨胀是这类游戏的主要死法。

## 12. 明确不做的清单

在旧宪法禁止清单之外新增：

- ❌ 战斗、追逐、逃跑、被吓
- ❌ 捕捉 / 圈养 / 繁殖野生动物
- ❌ 好感度衰减、朋友生气、被讨厌
- ❌ 体力条、饥饿惩罚、时间压力
- ❌ 讨价还价、价格波动、借贷、负数金钱
- ❌ 死亡、灭绝、濒危等字眼出现在童童能看到的文本里
- ❌ 婚恋系统（牧场物语有，我们不要——年龄不对）
- ❌ 任何形式的"排行""评级""段位"
- ❌ 需要**键盘打字**的交互（手写与绘画鼓励使用）
- ❌ 对童童的手写/绘画作品进行识别、评分或纠正
