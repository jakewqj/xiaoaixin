# 小丑鱼一家精灵图 · 美术需求 Prompt


---

请画一组**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**小丑鱼一家**,红海双带小丑鱼(学名 *Amphiprion bicinctus*,红海特有种)。这是儿童向游戏里的角色,但有一个物种辨识的硬性要求:

- **身上只有两条白色竖条纹,不是三条**——这是红海双带小丑鱼和我们平时熟悉的"尼莫"(眼斑双锯鱼/公子小丑,那种有三条白纹)最大的区别,一定不能画错
- 两条白纹外围镶着细细的黑色边线
- 体色是橙红色到深红棕色(红海双带小丑鱼成年后体色偏深,接近巧克力棕红色,不是特别鲜艳的橙色)
- 身体短圆,尾鳍圆钝(不是分叉尾)
- 性格设定"很吵,一家好几只"——需要画一组**至少 3 条、大小不一**的鱼(可以理解为父母 + 一两条小鱼),这样天然就是一个可以"数一数有几条"的数学素材

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **单条鱼 40 × 28 像素**(每一帧),画面里同时出现 3 条大小不一的鱼(建议按 1×、0.8×、0.6× 三档缩放) |
| 调色板 | **最多 10 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**⚠️ 尺寸需要你确认**:小丑鱼成鱼体长约 11–14 厘米,严格按比例尺(64px=1米)换算只有约 8px,太小看不清。这里按最小可用尺寸给了 40px,**没有严格遵守真实比例**,和「小金」的情况一样,如果你有更好的处理方式(比如整组鱼群做一个更大的合成画面而不是单条放大)告诉我。

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,一家几条鱼各自小幅度打转、穿梭的待机动作(呼应"很吵、闹哄哄"的性格,彼此动作节奏可以错开)
2. **swim.png** —— 4 帧,8fps,标准的小丑鱼快速抖动式游泳(小丑鱼游动姿态比较"抖",不是平滑滑行)
3. **talk.png** —— 4 帧,8fps,一家的鱼一起冒气泡/张嘴的动作,体现"抢话"的热闹感

交付文件(如果模型只能画单条鱼,就交付单条鱼的三套动画,场景里由代码做多条排布和缩放):
- `idle.png` = 40×4 = 160px 宽,28px 高
- `swim.png` = 40×4 = 160px 宽,28px 高
- `talk.png` = 40×4 = 160px 宽,28px 高

## 背景知识

- *Amphiprion bicinctus*(双带小丑鱼)是红海特有种,与海葵共生(出处标注"待核对",还没有更硬的文献来源)
- 小丑鱼一家住在「珊瑚花园」,和海葵住在一起,学习挂载是自然(颜色/共生)和英语

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 40px 的整数倍
3. 数一下白色条纹**必须是两条**,画成三条要退回去重画
4. 三个文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/clownfish_family/` 文件夹
