# 儒艮大婶精灵图 · 美术需求 Prompt

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色定位:她和小爱心是同一个物种,不是新设计一个角色

**儒艮大婶**是一只成年雌性儒艮(*Dugong dugon*),和小爱心一模一样的物种。这个角色出现在游戏情感的最高点——小爱心长大成年后,第一次见到"很多和我一样的"同类。**这份文档不是让你重新设计一只动物,而是复用小爱心的完整规格,只做个体差异化**,请先读一遍 `docs/xiaoaixin_art_prompt.md` 里对儒艮解剖结构的要求(分叉鲸尾、无背鳍、向下弯的吻部、桨状鳍肢),这些硬性规则儒艮大婶完全适用,不重复列一遍。

## 和小爱心的区别(个体差异,不是物种差异)

- 体型可以比小爱心成年态更浑圆敦实一点,毕竟是"大婶"辈分
- 皮肤上可以加一些**浅色的疤痕和斑驳纹理**(野生成年儒艮身上常见,来自船只螺旋桨、觅食摩擦、藻类附着等真实痕迹),小爱心作为主角保持干净光滑,大婶可以有这种"经历过岁月"的质感,但**不要画得太夸张吓人**,是温和的老年感,不是伤痕累累
- 基础色调**沿用小爱心的项目配色**:身体 `#8CA3B0`,腹部 `#C3D3D9`,描边 `#243642`——不要另起颜色,她们是同一个物种

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **192 × 64 像素**(和小爱心成年态完全一致) |
| 调色板 | **最多 16 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | `#243642` |

## 需要 3 套动画(比小爱心的 5 套少,不需要 eating/sleeping)

1. **idle.png** —— 4 帧,8fps,原地漂浮,动作比小爱心更沉稳、幅度更小
2. **swim.png** —— 6 帧,8fps,尾鳍上下拍打推进(和小爱心一样,不是左右摆),节奏更从容不迫
3. **talk.png** —— 4 帧,8fps,说话时的轻微动作

交付文件:
- `idle.png` = 192×4 = 768px 宽,64px 高
- `swim.png` = 192×6 = 1152px 宽,64px 高
- `talk.png` = 192×4 = 768px 宽,64px 高

## 背景知识

- 鲨鱼湾拥有全球最大儒艮种群,约 10000–11000 头,占世界总数约 1/8(出处:EBSCO Shark Bay 条目 / marinemammalhabitat.org,已核对)
- 儒艮大婶住在「乌拉梅尔草原」,是全游戏情感设计的高点场景,这一段设计要求"慢一点,别赶"

## 关于"上百头儒艮大集会"场景的说明

儒艮大婶所在的场景后续会有一个"大集会"演出(上百头儒艮聚在一起),那个场景大概率不会用这套精细精灵图去画上百个个体,而是需要一套更简化的远景剪影方案。**这份文档只负责儒艮大婶这一个近景对话角色,大集会场景的美术需求到时候另外单独写。**

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 192px 的整数倍
3. 文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/dugong_aunt/` 文件夹
4. 在浏览器里和小爱心放在一起对比,确认"一眼看出是同一个物种,但明显是不同的两个个体"
