# 放置说明（看完可删）

## 怎么放

把本文件夹里的东西**合并**进你现有的 `xiaoaixin/` 项目，不是替换。

```
xiaoaixin/
├── CLAUDE.md                  ← 你已有。把 CLAUDE_ADDENDUM_v2.md 的内容粘到末尾
├── CLAUDE_ADDENDUM_v2.md      ← 新增（粘完可删）
├── ROADMAP.md                 ← 新增
├── docs/
│   ├── GDD.md                 ← 新增
│   └── _archive/              ← 新增（把旧的 PLAN.md / PROMPTS.md 也挪进来）
├── content/
│   ├── config.json            ← 新增
│   ├── world.json             ← 新增
│   ├── npc.json               ← 新增
│   ├── facts.json             ← 新增
│   ├── dialogue.json          ← 你已有，不动
│   ├── knowledge.json         ← 你已有，不动
│   └── whitelist.json         ← 你已有，不动
└── assets/
    └── pet/
        ├── pet.json           ← 覆盖旧的（规格从 SVG 改成像素精灵）
        ├── pixel/             ← 空，放像素精灵表
        └── tongtong/          ← 空，放童童手绘版
```

## 放完立刻做四件事

1. **把 `CLAUDE_ADDENDUM_v2.md` 全文粘到 `CLAUDE.md` 末尾**，然后按它第十八章把三处旧条款标成【已作废】
2. **改掉后台密码**：`content/config.json` → `后台.密码`，现在是 `0000`
3. **把旧的 `PLAN.md` 和 `PROMPTS.md` 移进 `docs/_archive/`**，别留在根目录（Claude Code 会读到过时的计划）
4. 删掉 `assets/pet/idle.svg`（旧占位），删掉本文件

## 然后

```
cd xiaoaixin && claude
```

第一条发 `ROADMAP.md` 里的 **0.5-1**。一次只发一条。
