# 砗磲奶奶(巨砗磲)精灵图 · 美术需求 Prompt


---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## ⚠️ 先说一个需要你确认的设计问题

砗磲是**固着不动的贝类,没有脸、没有嘴、不会动**——它不像海龟海豚那样天生适合做一个"会说话的角色"。下面这份 prompt 里我给了一个处理方案(靠外套膜的开合来表现"说话"),但这是我的设计判断,不是照搬什么资料,**你觉得不对可以换方案**,比如干脆让它完全静止、只用文字气泡表示说话,不做任何贝壳开合动画。

## 角色

**砗磲奶奶**,一只巨砗磲(学名 *Tridacna maxima*)。这是红海珊瑚礁常见物种(出处标注为"待核对",还没有更硬的文献来源,先按通识资料画)。

- 贝壳边缘呈**波浪状扇贝纹路**,不是平直的直线
- 壳内侧、贝壳张开时露出的**外套膜(软体部分)有鲜艳的蓝绿色或紫色斑纹,带一点珠光/荧光质感**——这是砗磲最吸睛的特征,来自体内共生藻类,画的时候这块可以用比调色板限制稍微多一点的渐变色块来表现"珠光感"(如果调色板超限,可以用 2-3 种蓝绿色阶模拟渐变)
- 壳体本身颜色是米白到浅棕的珊瑚礁色调,表面可以有一些藻类或珊瑚碎屑的质感暗示
- 性格设定"不动,最年长,一次只说一句"——整体气质要显得沉稳、古老,不要设计成活泼的表情

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **64 × 48 像素** |
| 调色板 | **最多 12 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 不需要朝向区分(固着不动,正面视角即可) |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:巨砗磲(*T. maxima*,不是能长到 1 米以上的库氏砗磲 *T. gigas*)成体壳长一般在 30–40 厘米左右,按比例尺换算约 20–26px,考虑到它是场景里的"图鉴总入口"NPC,需要有一定视觉存在感,取整放大到 64×48。**这个放大幅度比其他角色更大,如果你觉得应该更贴近真实比例,告诉我调整。**

## 需要 2 套动画(数量比其他 NPC 少,因为它不会动)

1. **idle.png** —— 2 帧,4fps,外套膜极缓慢地微微张合,像呼吸一样,frame 间差异要很小,体现"几乎静止"的感觉
2. **talk.png** —— 4 帧,8fps,贝壳张开幅度变大一点、外套膜的珠光斑纹随之更明显,作为"说话中"的视觉反馈(不是真的有嘴在动)

交付文件:
- `idle.png` = 64×2 = 128px 宽,48px 高
- `talk.png` = 64×4 = 256px 宽,48px 高

## 背景知识

- *Tridacna maxima* 是红海珊瑚礁常见物种
- 砗磲奶奶住在「沙地浅滩」,少年期解锁,角色功能是图鉴系统的总入口,回答不知道的问题时会说"这个我也不知道,我们去问爸爸"——这是设计好的功能,不是失败
