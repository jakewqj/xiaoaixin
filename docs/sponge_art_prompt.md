# Sponge(宽吻海豚)精灵图 · 美术需求 Prompt

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**Sponge**,一只印度太平洋宽吻海豚(Indo-Pacific Bottlenose Dolphin,学名 *Tursiops aduncus*)。这是儿童向游戏里的角色,但外形要符合真实物种特征,并且要有一个**必须画出来的标志性道具**:

- **它的核心行为是用海绵护住吻部在海底觅食**——这是这个角色存在的全部意义(角色名字 Sponge 就来自这个行为),画的时候一定要有一个动作是**吻部顶着一小块米黄色/浅棕色的海绵**,在贴近海底的姿态下移动
- 体型比常见的宽吻海豚(*Tursiops truncatus*)更细长,吻部更细长,成年个体腹部常有深色斑点(可以画一点点腹部斑点增加辨识度,但不要画得太密影响整体简洁)
- 体色是灰色,背部深、腹部浅,分界线柔和不要像小爱心那样清楚分层
- 性格没有特别设定,但角色定位是"工程/创造思维"的代表——它是"发明了一个办法"的海豚,姿态可以设计得比较专注、若有所思

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **160 × 60 像素**(每一帧)——见下方尺寸依据 |
| 调色板 | **最多 12 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:宽吻海豚成年体长约 2.5 米左右,按 64px = 1 米换算约 160px,高度按接近 Dolly 但略粗壮的比例给 60px。**这个体长数字是一般资料估的,建议核对。**

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,原地漂浮的待机动作
2. **sponging.png** —— 6 帧,8fps,**这是这个角色最重要的一套动画**:头朝下贴近海底,吻部顶着一小块海绵,身体沿水平方向缓慢移动觅食的姿态,海绵要在每一帧里清楚可见
3. **talk.png** —— 4 帧,8fps,说话时的轻微点头动作

交付文件:
- `idle.png` = 160×4 = 640px 宽,60px 高
- `sponging.png` = 160×6 = 960px 宽,60px 高
- `talk.png` = 160×4 = 640px 宽,60px 高

## 背景知识

- 鲨鱼湾宽吻海豚会用海绵包住吻部在海底觅食,是野生动物工具使用的著名案例(出处:waholidayguide.com.au / 鲨鱼湾海豚研究通识,已核对)
- Sponge 住在「海豚湾」,成年期解锁,语言是英语,教育挂载是工程/创造思维——这个技能设定为"可以学会并带回红海用"

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 160px 的整数倍
3. **确认 sponging.png 里海绵清晰可辨**,这是这个角色的核心记忆点,画丢了这套图就没意义了
4. 文件改名为 `idle.png` / `sponging.png` / `talk.png`,放进 `public/assets/npc/sponge/` 文件夹
