# 石头爷爷(叠层石)精灵图 · 美术需求 Prompt

---

请画一张**像素风(pixel art)静物/精灵图**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## ⚠️ 这个角色和其他所有 NPC 都不一样,需要你确认设计方向

石头爷爷不是动物,是**叠层石(stromatolite)**——蓝藻堆积形成的岩石状结构,**没有脸、没有身体部位、完全不会动、不会游动**。它是这个游戏里唯一一个不是"生物角色"的 NPC。下面是我的处理方案,但这一整套思路都需要你确认,如果觉得不对,方向可以推翻重来:

- 不给它设计任何拟人化的脸或表情(眼睛嘴巴之类),保持它作为一块岩石的真实感,这是"原则 9:所有设定必须有真实出处"的体现——叠层石本来就没有脸
- 用几乎不动的画面本身来呼应它的性格设定"极慢,每天只说一句话"——这个限制本身就是内容,画面上的"静"要配合这一点
- 说话时不做张嘴之类的动画,建议用一个极小的气泡/微光作为"正在说话"的提示,而不是让石头本身产生动作

## 角色描述

- 外形是一个**圆顶状、层层堆叠的岩石土墩**,浸在浅水里,顶部露出水面一部分
- 表面有横向的**层状纹理**(叠层石最重要的科学特征就是一层一层的沉积纹路,画出这个纹理是这个角色辨识度的核心)
- 表面覆盖一层薄薄的、湿润反光的藻类薄膜,颜色是深灰绿到棕褐色,可以有轻微的湿润光泽感,但不要画成鲜艳的珊瑚或植物
- 整体气质要显得**古老、沉静、地质感强**,而不是可爱的卡通生物

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **72 × 48 像素** |
| 调色板 | **最多 8 色**(比其他角色更少,呼应它极简、沉静的性格) |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 不需要朝向区分(固定不动的地质构造) |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:叠层石在鲨鱼湾实际是成片的礁状结构,单个石丘从几十厘米到一米多不等,这里没有精确换算,按"一个能撑起一个 NPC 存在感的岩石土墩"目测给了 72×48,和游戏里其他角色的比例尺关系不严格对应(它本来就是背景地质构造,不是生物个体)。

## 需要的动画极少,这是刻意的

1. **idle.png** —— **2 帧,4fps**,画面几乎一样,只有湿润表面的反光有极细微的差异(几乎看不出在动),体现"很慢很慢"
2. 不需要单独的 talk 动画。说话时的反馈建议用代码层面加一个小气泡或微光特效来做,不需要额外出图(如果你想额外画一个,可以加一版 **glow.png**,2 帧,4fps,表面某个小区域极轻微地亮一下又暗下去,像是"回应"的意思)

交付文件:
- `idle.png` = 72×2 = 144px 宽,48px 高
- (可选)`glow.png` = 72×2 = 144px 宽,48px 高

## 背景知识

- 鲨鱼湾叠层石由蓝藻堆积形成,是地球上最古老的生命形式之一;鲨鱼湾是少数由碳酸盐而非造礁珊瑚主导的海洋区域(出处:UNESCO 世界遗产名录 No.578,已核对)
- 石头爷爷住在「叠层石浅滩」,成年期解锁,是全游戏唯一"每天只说一句话"的角色——这个限制本身就是在教"很久很久"是什么意思,代码层面不会绕过它

---

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 72px 的整数倍
3. 文件放进 `public/assets/npc/stone_grandpa/` 文件夹
4. 在浏览器里确认它看起来是一块岩石,不是一个有表情的生物——如果看起来太"卡通生物"了,需要回来重新讨论方向
