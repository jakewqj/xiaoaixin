# 小爱心 · 六周开发计划

**节奏**:每周末 2–3 小时
**铁律**:每个阶段结束**必须是能给童童玩的**。这是防止烂尾的唯一有效约束。

---

## 核心循环

```
换气提醒 → 陪伴互动 → 海草床维护 → 生态变好 → 小爱心成长 / 解锁新海域
```

养的其实是**一片海**,小爱心是入口。

---

## 儒艮特性 → 游戏机制映射

| 真实特性 | 游戏机制 |
|---|---|
| 必须浮出水面换气(约 3–5 分钟一次) | session 内定时浮上水面,点击帮它换气 |
| 只吃海草(每天约 30kg) | 海草床种植与养护系统 |
| 移动极慢,性情温和 | 治愈慢节奏,无紧迫感 |
| 幼崽体色淡,长大变成石板灰 | 成长阶段的视觉标志 |
| 幼崽跟着妈妈约 18 个月 | 成长阶段的时间尺度 |
| 妈妈把幼崽托上水面换第一口气 | 换气机制的情感来源 |
| IUCN 易危物种 | 图鉴科普(轻,不说教) |

---

## 第 0 周 · 准备(不写代码)

- [ ] 童童给小爱心**想 5 句口头禅** → 写进 `content/dialogue.json`
- [ ] 一起选主色 / 给海草起名字
- [ ] 确认素材规格(见 `assets/pet/pet.json`)
- [ ] 手稿**暂缓**,先用占位 SVG

**验收**:`dialogue.json` 里有 5 句童童说的话。

---

## 第 1 周 · 它活了

- [ ] Vite + React + TS + Tailwind 项目初始化
- [ ] 一屏竖屏海洋背景(三层水色渐变)
- [ ] 小爱心从 `/assets/pet/idle.svg` 加载,缓慢左右漂移 + 轻微上下浮动
- [ ] 点击它 → 播放音效 + 转身 / 轻微反应

**验收**:给童童看一眼。这一周的反馈通常最好。

---

## 第 2 周 · 换气 + 饱食度 + 对话

- [ ] 换气机制:每 3 分钟游上水面吐泡泡,点击完成换气(泡泡位置读 `pet.json` 的 `blowhole` 锚点)
- [ ] 饱食度:**图标表示,不显示数字**
- [ ] 喂海草(此时海草可以先是无限的)
- [ ] 剧本对话系统:读 `content/dialogue.json`,小爱心说短句 + 2–3 个带图标的选项
- [ ] localStorage 存档,关掉再打开状态还在

**验收**:童童能独立完成一次「换气 → 喂食 → 对话」。

---

## 第 3 周 · 海草床

- [ ] 可以种海草,海草分「新芽 → 长成」两阶段
- [ ] 长成的海草才能喂
- [ ] 海水清澈度:海草多 → 水变清;海草少 → 水变浑(纯视觉反馈,不做惩罚)

**验收**:童童理解「种海草 → 水变干净」这个因果。

**注意**:生态系统只做这一层,不要加污染物、pH 值、鱼群链条。

---

## 第 4 周 · 成长 + 相册 + 手稿替换

- [ ] 小爱心按累计游玩天数成长:幼崽 → 少年 → 成年(体色由淡奶油色逐渐变成石板灰)
  - 小爱心是**雌性**,不会长獠牙。獠牙只有雄性儒艮成年后才萌出,这条不能用作她的成长标志
  - 真实时间尺度参考:幼崽期约 18 个月跟着妈妈,雌性 6–17 岁性成熟
- [ ] 相册页:记录「第一次换气」「第一次种海草」「小爱心说过的话」
- [ ] 相册可截图,发给爷爷奶奶
- [ ] ⭐ **手稿替换仪式**:当着童童的面,把她画的 4 张 PNG 拖进 `/assets/pet/`,刷新页面

**验收**:小爱心变成童童画的样子。这一秒是整个项目的高光。

---

## 第 5 周 · 打磨 + 上线

- [ ] 音效补全(建议直接录你和童童的声音)
- [ ] PWA manifest + 图标(用童童的画)
- [ ] 部署 Cloudflare Pages
- [ ] 装到 iPad 主屏

**验收**:不开浏览器地址栏,从桌面图标就能打开。

---

## 第 6 周 · 可选扩展

**A. 图鉴(推荐先做这个)**
每解锁一个成长阶段,给一张真实儒艮知识卡:吃什么 / 为什么被误认成美人鱼 / 为什么现在很少了。轻科普,不说教。

**B. AI 对话(先满足全部四个条件再做)**

| 风险 | 必须的处理 |
|---|---|
| 延迟 | 「小爱心在想…」吐泡泡动画 + 流式输出 |
| 失控 | system prompt 锁死:只谈海洋/海草/心情;永不提暴力恐怖;永不索取个人信息;永不说「不要告诉爸爸妈妈」 |
| 断网/报错 | 本地兜底台词库,**绝不白屏**(孩子看不懂 error) |
| 词汇超纲 | 明确要求「6 岁孩子能懂的词,每句不超过 15 字,不用成语」 |

**外加一条务必做的**:把对话记录存进 localStorage,你自己定期翻。
不是监控童童,是**检查 AI 输出质量**——这类项目最容易出问题的地方,是模型某天开始输出让孩子困惑的内容,而孩子不会主动告诉你。

**上线顺序**:AI 对话做完后,先只对你自己开放,你替她试玩一周再交给她。

---

## 一个额外收益

第 2 周的剧本对话系统做完,你其实拿到了一个**可以和童童一起写内容的系统**。

她说「我想让小爱心会讲笑话」,你当晚加进 `dialogue.json`,第二天她就看到了。

这个反馈闭环,可能比游戏本身更值钱。
