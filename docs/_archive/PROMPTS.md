不要把整周的任务合并成一句发出去——那是烂尾的开始。

## 第 1 周

### 1-1 项目初始化

```
先读一遍 CLAUDE.md。

用 Vite 初始化一个 React + TypeScript 项目,配好 Tailwind CSS。
保持最小配置,不要引入任何额外依赖,不要加路由。
把 assets/ 和 content/ 放到 public/ 下,保证能通过 fetch 读到。

做完告诉我怎么启动开发服务器,以及你创建/修改了哪些文件。
```

### 1-2 一片海

```
做一屏手机竖屏的海洋背景,占满整个视口。
用 CLAUDE.md 里定义的三个水色做垂直渐变:
上方 water-shallow,中间 water-mid,底部 water-deep,最下面一条 sand 色的沙底。

先只做背景,不要放任何生物。
```

### 1-3 小爱心出现

```
在海的中间放上小爱心。

- 从 /assets/pet/idle.svg 加载,不要把 SVG 内联写进组件
- 宽度约占屏幕的 45%
- 用 CSS transform 让它非常缓慢地左右漂移(单程约 12 秒)
- 叠加一个轻微的上下浮动(周期约 4 秒,幅度很小)
- 遵守 prefers-reduced-motion

儒艮移动极慢,宁可慢到你觉得「是不是没动」,也不要快。
```

### 1-4 点击反应

```
点击小爱心时:
- 它轻微放大再恢复(约 300ms)
- 水平翻转朝向
- 播放一个短音效(先用一个占位音频文件,路径 /assets/sfx/tap.mp3,文件我稍后放)
- 音频加载失败时静默处理,绝不能报错或白屏

点击热区至少 56x56 px。
```

**→ 这一步做完,拿给童童看。**

## 第 2 周

### 2-1 存档

```
建立存档系统。localStorage,单个 key:xiaoaixin_save。

存档结构包含:创建时间、累计游玩天数、上次游玩时间、饱食度、已解锁的相册事件。
写一个 useSave hook 统一读写,不要在组件里散着调 localStorage。
存档损坏或不存在时,静默创建一份新的,不要弹任何提示。
```

### 2-2 换气

```
实现换气机制,注意只在页面打开期间生效,禁止任何后台通知。

- 每 3 分钟,小爱心缓慢游到水面
- 从 pet.json 的 blowhole 锚点位置冒出泡泡(锚点必须读 JSON,不许硬编码)
- 点击它 → 泡泡散开,播放音效,它慢慢沉回中层
- 如果她没点,小爱心就一直在水面等着,不产生任何负面后果
```

### 2-3 饱食度与喂食

```
加饱食度。

- 用一排小海草图标表示,共 5 格,不显示任何数字和百分比
- 随时间缓慢下降,降到 0 也不产生任何惩罚,只是小爱心会说「我有点饿了」
- 加一个喂食按钮,喂一次涨一格,播放吃东西音效
- 吃的时候切换到 eating 形象(现在还没有这张图,先复用 idle,但代码要按能切换的方式写)
```

### 2-4 对话系统

```
实现剧本对话系统,读 /content/dialogue.json。

- 小爱心头顶弹出气泡,显示 text
- 下方显示 options,每个选项是「大图标 + 短文字」,图标必须足够大到不识字也能认
- 加一个拼音开关,打开时在文字下方显示 pinyin 字段
- 文字最小 24px,用站酷快乐体
- 触发时机按 JSON 里「触发」字段的描述来接

先把 6 个场景全部接通,不要自己新增台词。
```

## 通用救急 prompt

**它开始自作主张时:**
```
停。重读 CLAUDE.md 的「绝对禁止清单」,然后告诉我刚才哪一条越界了,并撤回。
```

**它一次改太多时:**
```
你这次改动太大了。回退到只完成我明确要求的那一件事,其余的先别做。
```

**代码乱了时:**
```
先不写新功能。把当前代码里重复的部分整理一下,告诉我现在的文件结构和各自的职责。
```
