# 阿玳(玳瑁海龟)精灵图 · 美术需求 Prompt


---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**阿玳**,一只玳瑁海龟(Hawksbill Turtle,学名 *Eretmochelys imbricata*)。这是儿童向游戏里的角色,但外形要符合真实物种特征——**要能一眼看出它和绿绿(绿海龟)不是同一种龟**:

- **嘴巴尖细、向下弯曲,像鸟喙(鹰嘴)**——玳瑁的英文名 Hawksbill 就是"鹰嘴"的意思,这是它和绿海龟圆钝喙嘴最大的区别,一定要画出尖喙感
- 背甲的甲片是**一片片叠瓦状重叠**的(imbricate),不是绿绿那种光滑连片的壳,边缘因此显得有锯齿状轮廓
- 背甲颜色是琥珀色、棕色、黑色交织的**玳瑁纹**(高对比、大块斑纹,比绿绿的橄榄色更艳丽、更有花纹感)
- 头部前方眼睛上方有**两对**额鳞(绿海龟只有一对,这个细节很小可以不用抠得太细,但整体头部结构要比绿绿的更狭长)
- 性格设定是"慢,长句,讲故事的人"——动作要比绿绿更迟缓、更从容,不要画得灵活敏捷

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **88 × 52 像素**(每一帧)——见下方尺寸依据 |
| 调色板 | **最多 14 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:成年玳瑁体长可达 90 厘米(出处:divessi.com 红海潜水资料,已核对),按 64px = 1 米换算约 58px,加上鳍肢伸展的视觉宽度取整到 88×52。比绿绿(96×56)略小一圈,符合真实体型差异。

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,原地缓慢漂浮,动作幅度比绿绿更小、更沉稳
2. **swim.png** —— 6 帧,8fps,前肢划水推进,节奏比绿绿慢
3. **talk.png** —— 4 帧,8fps,说话时头部非常轻微的点动,配合"慢、长句、讲故事"的性格,动作要显得从容不迫,不要匆忙

交付文件:
- `idle.png` = 88×4 = 352px 宽,52px 高
- `swim.png` = 88×6 = 528px 宽,52px 高
- `talk.png` = 88×4 = 352px 宽,52px 高

## 背景知识

- 玳瑁海龟是红海珊瑚礁的代表物种,以海绵、海葵、水母为食,体长可达 90 厘米、约 80 公斤(出处:divessi.com 红海潜水资料)
- 阿玳住在「老沉船」,是少年期解锁的邻居,角色功能是讲故事(历史、美人鱼传说、人与海的关系)

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 88px 的整数倍
3. 三个文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/ada/` 文件夹
4. 在浏览器里对比一下阿玳和绿绿的壳纹、嘴型是不是能一眼区分开
