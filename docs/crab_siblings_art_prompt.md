# 招潮蟹兄妹精灵图 · 美术需求 Prompt

---

请画一组**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**招潮蟹兄妹**,两只招潮蟹(Fiddler Crab)。这是这个游戏里"对称与不对称"数学概念的天然教具,画的时候**这一条是核心**:

- **哥哥**:一只螯特别大(可以和整个身体差不多大)、另一只螯很小,这是雄性招潮蟹的真实特征,大螯用来挥舞示威和求偶炫耀(英文名 Fiddler Crab 就是因为它挥螯的样子像拉小提琴)
- **妹妹**:两只螯**大小相同**、都比较小,这是雌性招潮蟹的真实特征
- 兄妹俩放在同一张场景里,一大一小螯 vs 两只小螯的对比要清楚,这是设计的重点,不是随便画两只蟹
- 蟹壳是扁平的横长方形,眼睛长在细长的眼柄上,横着走路
- 体色可以用橙棕色或砖红色,两只可以有细微的深浅区别方便区分谁是谁
- 性格设定"抢话"——待机动作可以做成两只蟹交替挥螯,像在抢着说话

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **单只蟹 32 × 20 像素**(每一帧),两只放在同一场景里 |
| 调色板 | **最多 10 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右(或正面均可,招潮蟹经常横着走,正面视角也说得通) |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**⚠️ 尺寸需要你确认**:招潮蟹实际体型很小(甲壳宽 2–5 厘米),严格按比例尺换算不到 3px,完全看不清。这里按最小可用尺寸给了 32px,和小金、小丑鱼一家一样是"看得清优先"而不是"比例精确优先",如果你有更好的处理方式告诉我。

## 需要 2 套动画

1. **idle.png** —— 4 帧,8fps,兄妹俩交替横走 + 哥哥挥舞大螯的待机动作(这是招潮蟹最标志性的行为,一定要画出"挥"的弧线感)
2. **talk.png** —— 4 帧,8fps,两只蟹的螯同时开合,像在抢着说话

交付文件:
- `idle.png` = 32×4 = 128px 宽,20px 高(单只蟹;如果模型能直接画兄妹同框的合成画面更好,按合成画面的实际宽度交付)
- `talk.png` = 32×4 = 128px 宽,20px 高

## 背景知识

- 雄性招潮蟹有一大一小两只螯(出处:基础生物学,已核对)
- 招潮蟹兄妹住在「红树林边」,只在退潮时出现,亚成年期解锁,学习挂载是数学(对称与不对称)

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 32px 的整数倍
3. **确认哥哥的大小螯差异和妹妹的对称双螯差异清晰可辨**,这是这组角色存在的全部意义
4. 文件改名为 `idle.png` / `talk.png`,放进 `public/assets/npc/crab_siblings/` 文件夹
