# 小爱心精灵图 · 美术需求 Prompt

复制下面这段直接发给 Gemini / Kimi 等生图模型(网页端或 CLI 都可以,这段话本身就是完整输入,不依赖上传参考图)。

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,**不要**平滑渐变、不要写实光影、不要照片级质感。

## 角色

**小爱心**,一只雌性儒艮(Dugong,学名 *Dugong dugon*)。这是一个爸爸做给 6 岁女儿玩的电子宠物游戏的主角,外形要**可爱但生物特征必须真实**,不能因为要讨好而画错身体结构——尤其是下面这条:

- **尾巴是分叉的鲸尾状(fluked tail)**,水平方向、末端两叶中间有一个浅凹口,像小鲸鱼或海豚的尾巴。**绝对不要画成海牛(manatee)那种圆桨状、不分叉的尾巴**——这是儒艮和海牛最容易被画错、也最容易被认错的地方。
- 吻部粗壮、向下弯曲,末端布满短硬的感觉毛(须),因为儒艮是低头拱食海底海草长大的,嘴巴的朝向和形状是为"贴地啃食"服务的,不是朝前的
- 没有背鳍(儒艮和海牛都没有背鳍,光滑的背部)
- 前肢是一对桨状鳍肢,没有后肢
- 身体呈纺锤形,浑圆敦实,不是海豚那种流线细长的身材
- 眼睛小而圆,位置在吻部根部偏上
- 皮肤光滑,颜色是均匀的灰蓝色,不要花纹、不要斑点

## 技术规格(必须严格遵守,否则没法用)

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **192 × 64 像素**(每一帧,这是成年基准体型) |
| 调色板 | **最多 16 色**(含描边和透明) |
| 主体颜色 | 身体 `#8CA3B0`(灰蓝),腹部 `#C3D3D9`(浅灰白)——**这两个色号已经定死,不要自己换颜色**,腹部只在身体下半部分露出一点,不要画成大面积双色分割 |
| 描边色 | `#243642`(墨蓝色),统一描边粗细 |
| 背景 | **透明**,PNG 格式 |
| 抗锯齿 | **不要**,边缘保持硬像素 |
| 朝向 | 固定**朝右** |

## 关键:5 个身体部位必须落在指定位置

游戏代码里已经写死了几个"锚点"坐标(换气泡泡从鼻孔冒出来、点击嘴巴/眼睛/尾巴尖/肚子会有反应,全靠这几个点和画面对上)。**画面里对应的身体部位,大致要出现在下面这些位置**(以整张 192×64 画布的左上角为 (0,0),横向 0→192 是从左到右,纵向 0→64 是从上到下):

| 部位 | 位置(占画布宽/高的百分比) | 大概像素坐标 |
|---|---|---|
| 鼻孔(blowhole) | 宽 80%、高 30% | 约 (154, 19) |
| 嘴(mouth) | 宽 86%、高 60% | 约 (165, 38) |
| 眼睛(eye) | 宽 75%、高 38% | 约 (144, 24) |
| 尾巴尖(tailTip) | 宽 10%、高 50% | 约 (19, 32) |
| 肚子中心(bellyCenter) | 宽 55%、高 62% | 约 (106, 40) |

翻译一下就是:头朝右占画面右侧约 1/4,鼻孔和眼睛在头顶偏右上方,嘴在头的最右端偏下(因为吻部向下弯),尾巴在画面最左边中间。**画好之后按这个表自查一遍位置对不对,位置差太远的话游戏里点击热区会跟画对不上。**

## 需要 5 套动画,每套是一张"横向排列的帧序列图"(左到右依次是第 1、2、3…帧,帧宽固定 192px):

1. **idle.png** —— 4 帧,8fps,原地漂浮,身体极轻微起伏(呼吸感),不完全静止
2. **swim.png** —— 6 帧,8fps,游泳循环。**关键**:儒艮和海牛目动物是靠尾鳍**上下**拍打前进的,不是像鱼那样左右摆尾——这一点画反了会显得像鱼不像哺乳动物
3. **eating.png** —— 4 帧,8fps,低头俯身,用吻部拱贴海底啃食海草的动作,身体略微前倾下沉
4. **surfacing.png** —— 4 帧,8fps,朝斜上方游向水面换气的姿态,头略微上扬,鼻孔准备露出水面
5. **sleeping.png** —— 2 帧,4fps(比其他动画慢一半),悬浮不动,只有极轻微的起伏,眼睛可以画成微闭

也就是总共要交付 5 张 PNG:
- `idle.png` = 192×4 = 768px 宽,64px 高
- `swim.png` = 192×6 = 1152px 宽,64px 高
- `eating.png` = 192×4 = 768px 宽,64px 高
- `surfacing.png` = 192×4 = 768px 宽,64px 高
- `sleeping.png` = 192×2 = 384px 宽,64px 高

## 背景知识(帮助生成更准确)

- 儒艮是海牛目(Sirenia)哺乳动物,不是鱼,必须定期浮出水面用肺呼吸(这是游戏里换气机制的科学依据)
- 儒艮以海草为食,用向下弯曲的吻部拱开海底泥沙啃食海草的根茎,这是它和海牛(海牛主要吃水生植物、吻部没那么向下弯)的一个区别特征
- 这是给 6 岁小朋友玩的游戏,角色要圆润可爱、有亲和力,但**不能靠改动物学特征来卖萌**——尾巴分叉、没有背鳍、上下摆尾这几条是硬性底线

## 成长阶段说明(不用画多套图)

游戏里小爱心会"长大",但不是靠画新图实现的——同一张精灵表按体型缩放(幼年 0.5 倍到成年 1.0 倍),颜色深浅也是代码用滤镜调的。**你只需要画一套成年基准的图**,不用额外画幼年/少年版本。

## 拿到图之后怎么处理

1. 检查每张图确实是**透明背景**、**没有被模型自动加白边或阴影**
2. 确认帧宽严格等于 192px 的整数倍(比如 idle 应该正好 768×64),尺寸不对要裁剪对齐
3. 对照上面"5 个身体部位位置"表,目测一下鼻孔、嘴、尾巴尖是不是大致落在该在的地方,偏太多就退回去改
4. 五个文件按文件名放进 `public/assets/pet/pixel/` 文件夹
5. 在浏览器里看一眼:换气时泡泡是不是从鼻孔冒出来的、点嘴巴点眼睛的反应位置对不对。偏了不用改图,改 `public/assets/pet/pet.json` 里的「锚点」数值就行
