# 火烈鸟精灵图 · 美术需求 Prompt

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**火烈鸟**,大红鹳(学名 *Phoenicopterus roseus*)。这是游戏里少数不游泳、站在浅水里的角色,姿态设计和其他海洋动物不一样:

- 细长的双腿、S 形长脖子、末端向下弯钩的粗喙(喙尖是黑色,喙的其余部分是粉色到浅灰色)
- 全身粉红色羽毛——**这一点本身就是这个角色要教给童童的知识:"我的颜色是吃出来的",粉色来自食物里的类胡萝卜素,不是天生的**,所以颜色要画得明确、饱和,让人一眼记住"粉色"这个特征
- 经典站姿是**单腿站立、另一条腿收起藏在羽毛里**,这是火烈鸟最标志性的休息姿势,idle 动作建议用这个
- 整体是"站立型"角色,画面里高度大于宽度,和其他游泳动物的横向构图不同

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **56 × 88 像素**(每一帧,高大于宽,和游泳类角色的横构图相反)——见下方尺寸依据 |
| 调色板 | **最多 10 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右(侧面站姿最容易看清腿和脖子的形态) |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:成年大红鹳站立高度约 1.2–1.5 米,取约 1.3 米,按 64px = 1 米换算约 83px,取整到 88px 高,身形纤细取宽度 56px。

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,经典单腿站立 + 轻微晃动的休息姿态
2. **eating.png** —— 4 帧,8fps,**倒头觅食**:火烈鸟真实的进食方式是把头倒过来伸进水里,用喙做过滤觅食(这是它区别于其他鸟类最独特的行为,一定要画出"头朝下"的姿态,不要画成普通鸟类低头啄食的样子)
3. **talk.png** —— 4 帧,8fps,脖子和头部小幅度点动/转向的动作

交付文件:
- `idle.png` = 56×4 = 224px 宽,88px 高
- `eating.png` = 56×4 = 224px 宽,88px 高
- `talk.png` = 56×4 = 224px 宽,88px 高

## 背景知识

- 波斯湾有大红鹳分布(出处标注"待核对",还没有更明确记载海湾火烈鸟分布的来源,先按通识资料画);粉色来自食物中的类胡萝卜素是鸟类色素学的通识知识,已核对
- 火烈鸟住在「红树林边」,和招潮蟹兄妹是邻居,亚成年期解锁

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 56px 的整数倍
3. 文件改名为 `idle.png` / `eating.png` / `talk.png`,放进 `public/assets/npc/flamingo/` 文件夹
4. 在浏览器里确认它是"站着的",和其他游泳角色放在同一场景里高度比例看起来合理
