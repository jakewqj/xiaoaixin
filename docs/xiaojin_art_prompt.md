# 小金(幼年金鲹)精灵图 · 美术需求 Prompt


---

请画一条**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**小金**,一条幼年金鲹(Juvenile Golden Trevally,学名 *Gnathanodon speciosus*)。这是儿童向游戏里的角色,但外形要符合真实物种特征——**幼年和成年金鲹长得完全不一样,一定要画幼年版**:

- 幼年金鲹身体呈**鲜艳的金黄色**,身上有 **5–11 条竖直的黑色条纹**,像小老虎鱼一样,这是它和成年个体(成年是银白色、条纹消失)最大的区别,也是它辨识度的全部来源
- 身体侧扁、卵圆形,嘴巴前突可伸缩(捕食小型甲壳类的适应特征),没有牙齿的凶相,整体看起来圆润讨喜
- 鱼鳍呈半透明的淡黄色
- 性格设定是"黏人、模仿"——它的核心机制是"复读":跟着小爱心/童童说什么它就说一遍。可以画成一直紧贴在旁边、姿态像跟屁虫的样子

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **48 × 32 像素**(每一帧)——见下方尺寸依据,**这个尺寸已经不是严格按体长比例算的** |
| 调色板 | **最多 10 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**⚠️ 尺寸需要你确认**:幼年金鲹实际很小(几厘米到十几厘米),如果严格按小爱心的比例尺(64px = 1 米)换算,画面里只有约 10px 宽,太小看不清也没法做动画。这里先按"游戏里看得清"的最小可用尺寸给了 48×32,**没有严格遵守真实比例**,如果你觉得应该更小或者有别的处理方式(比如靠近小爱心时放大一点),先告诉我再定稿。

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,贴着小爱心附近打转、警觉张望的待机动作
2. **swim.png** —— 4 帧,8fps,快速摆尾跟随游动
3. **talk.png** —— 4 帧,8fps,张嘴"复述"的动作,可以做得比较夸张一点(嘴巴一开一合),因为它的角色功能就是重复别人的话

交付文件:
- `idle.png` = 48×4 = 192px 宽,32px 高
- `swim.png` = 48×4 = 192px 宽,32px 高
- `talk.png` = 48×4 = 192px 宽,32px 高

## 背景知识

- 幼年金鲹会跟随鲨鱼、石斑鱼、儒艮等大型动物游动以求庇护,有时也会跟着潜水员(出处:scubatravel.co.uk 红海生物资料)
- 小金住在红海浅滩,不固定在某个地点,而是跟随小爱心到处走
- 这是给 6 岁小朋友设计的"安全复读"角色:她说什么小金就学一遍(中英文都行),**不判断说得像不像,不评分**

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 48px 的整数倍
3. 三个文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/xiaojin/` 文件夹
4. 在浏览器里看一眼跟着小爱心游动时大小是否合适,太小可以回来这份文档调整画布尺寸重画
