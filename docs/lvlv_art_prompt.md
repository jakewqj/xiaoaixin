# 绿绿(绿海龟)精灵图 · 美术需求 Prompt


---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变、不要写实光影。

## 角色

**绿绿**,一只绿海龟(Green Sea Turtle,学名 *Chelonia mydas*)。这是儿童向游戏里的角色,但外形要符合真实物种特征:

- 甲壳(背甲)呈**光滑的椭圆形**,边缘不重叠——这是和玳瑁海龟(另一个 NPC「阿玳」)最大的区别,阿玳的甲壳是一片片叠瓦状重叠的,绿绿的不是
- 背甲颜色是橄榄绿到棕色的**斑驳大理石纹**(不是纯绿色——"绿"指的是它体内脂肪的颜色,不是壳的颜色,但为了辨识度壳可以带一点绿褐色调)
- 头部相对小,嘴是**没有牙齿的角质喙状嘴**,边缘略带锯齿感(适应啃食海草和海藻)
- 四肢是桨状鳍肢,前肢长、后肢短
- 性格设定是"话痨,什么都讲一遍"——可以在待机动作里加一点探头张望的小动作,显得话多好奇

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **96 × 56 像素**(每一帧)——见下方尺寸依据 |
| 调色板 | **最多 14 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边,和小爱心一致 |

**尺寸依据**:成年绿海龟背甲长约 1–1.2 米(常见引用约 1 米),按小爱心的比例尺(64px = 1 米)换算,甲壳本体约 64px,前后鳍肢伸展后整体视觉长度更长,取整到 96px 宽、56px 高。**这个数字是按一般资料估的,不是精确文献值,建议正式定稿前再核对一次。**

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,原地缓慢划水漂浮,头部偶尔探一下(呼应"话痨"性格)
2. **swim.png** —— 6 帧,8fps,前肢像划桨一样上下划动推进(绿海龟主要靠前肢"飞"着游,后肢只用来控制方向,不要画成四肢一起划水)
3. **talk.png** —— 4 帧,8fps,说话时头部小幅点动或张合嘴的动作

交付文件:
- `idle.png` = 96×4 = 384px 宽,56px 高
- `swim.png` = 96×6 = 576px 宽,56px 高
- `talk.png` = 96×4 = 384px 宽,56px 高

## 背景知识

- 绿海龟和蠵龟会跨洋洄游数千公里,回到出生地产卵(出处:海龟洄游研究通识)
- 绿绿住在红海浅滩的「家海草床」,是小爱心一开始就认识的邻居,角色功能是「信使」——以后会带来远方的消息
- 这是给 6 岁小朋友玩的游戏,角色要友善圆润,但甲壳形状、喙状嘴、鳍肢比例这些物种特征不能为了可爱牺牲掉

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 96px 的整数倍
3. 三个文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/lvlv/` 文件夹
4. 在浏览器里看一眼朝向、描边风格跟小爱心和 Dolly 是否协调
