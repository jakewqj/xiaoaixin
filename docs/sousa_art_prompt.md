# Sousa(印度洋驼背豚)精灵图 · 美术需求 Prompt

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## 角色

**Sousa**,一只印度洋驼背豚(Indian Ocean Humpback Dolphin,学名 *Sousa plumbea*)。这是儿童向游戏里的角色,但外形要符合真实物种特征,并且要能和另一个海豚角色 Dolly(旋转海豚)明显区分开:

- **背部靠近背鳍的位置有一个隆起的脂肪驼峰**,背鳍长在这个驼峰上面——这是驼背豚属(Sousa)最标志性的特征,"驼背"这个名字就是来自这里,一定要画出来
- 体型比 Dolly 更粗壮敦实,不是细长流线型
- 吻部(嘴)比 Dolly 更长更细
- 体色是灰色调(阿拉伯湾种群是灰色,**不是**中华白海豚那种偏粉白色——这是容易搜到错误参考图的地方,画的时候不要参考"粉色海豚"的图)
- 性格设定"稳重、害羞",动作幅度要比 Dolly 小、更内敛,不要设计跳跃类动作

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **160 × 68 像素**(每一帧)——见下方尺寸依据 |
| 调色板 | **最多 12 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 固定朝右 |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:印度洋驼背豚成年体长约 2.3–2.8 米,取中间值约 2.5 米,按 64px = 1 米换算约 160px,高度按比 Dolly(112×48)更粗壮的体型比例放大到 68px。**这个体长数字是一般资料估的,不是精确文献值,建议核对。**

## 需要 3 套动画

1. **idle.png** —— 4 帧,8fps,原地缓慢起伏,姿态沉稳
2. **swim.png** —— 6 帧,8fps,平稳游动,不要 Dolly 那种跳跃感,尾鳍摆动幅度更小更从容
3. **talk.png** —— 4 帧,8fps,说话时有点"害羞"的感觉——比如身体略微侧转、不完全正对镜头的小动作

交付文件:
- `idle.png` = 160×4 = 640px 宽,68px 高
- `swim.png` = 160×6 = 960px 宽,68px 高
- `talk.png` = 160×4 = 640px 宽,68px 高

## 背景知识

- 南阿拉伯湾栖息约 700 头印度洋驼背豚(出处:marinemammalhabitat.org 南部海湾资料,已核对)
- Sousa 住在「咸水浅湾」,亚成年期解锁,语言是英语,但和 Dolly 的短促口语不同——Sousa 说得慢、句子更长,是英语进阶层

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 160px 的整数倍
3. 三个文件改名为 `idle.png` / `swim.png` / `talk.png`,放进 `public/assets/npc/sousa/` 文件夹
4. 在浏览器里跟 Dolly 放一起对比,确认驼峰、体型、灰色调这几点能一眼区分两只海豚
