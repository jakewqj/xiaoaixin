# 珍珠爷爷(珍珠贝)精灵图 · 美术需求 Prompt

---

请画一只**像素风(pixel art)精灵表(sprite sheet)**,风格是《星露谷物语》(Stardew Valley)那种低分辨率、16 色以内、无抗锯齿(no anti-aliasing)的像素画:圆润、干净描边、每个像素都是实色块,不要平滑渐变。

## ⚠️ 先说一个和「砗磲奶奶」一样的设计问题

珍珠贝也是**固着不动的贝类,没有脸、没有嘴**。这份 prompt 沿用了砗磲奶奶那份文档里的方案(靠贝壳开合表现"说话"),保持两个贝类角色的处理方式一致。如果你想换方案,两个一起换。

## 角色

**珍珠爷爷**,一只珍珠贝(学名 *Pinctada radiata*)。真实的阿拉伯湾珍珠贝,历史上是采珠文化的根源(出处:CMS 阿拉伯湾章节 / 胡代里亚特岛贝丘考古,已核对)。

- 壳体比砗磲小得多、更扁平,呈**不规则圆形到耳形**,表面粗糙、有层状生长纹,颜色是暗褐色到灰黑色,不起眼、不鲜艳
- 壳内侧张开时露出**珍珠母贝(nacre)的乳白色珠光光泽**,可以隐约画出一颗小小的珍珠
- 和砗磲奶奶"艳丽"的外套膜不同,珍珠爷爷的美**藏在里面**——外表朴素、打开后才有光泽,这个反差正好配合他"有耐心,喜欢等,爱讲以前"的性格
- 通常以足丝(byssus)固着在礁石或其他贝壳上,可以画一小撮丝状物固定底部

## 技术规格

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **32 × 24 像素**——见下方尺寸依据 |
| 调色板 | **最多 10 色** |
| 背景 | 透明,PNG 格式 |
| 抗锯齿 | 不要,边缘硬像素 |
| 朝向 | 不需要朝向区分(固着不动) |
| 描边 | 统一用 `#243642` 墨蓝色描边 |

**尺寸依据**:珍珠贝 *Pinctada radiata* 成体壳长一般 6–8 厘米,比巨砗磲小很多,这里给了比砗磲奶奶(64×48)明显更小的画布,体现体型差异,同时保留最低可辨识度。

## 需要 2 套动画

1. **idle.png** —— 2 帧,4fps,壳体几乎不动,只有极轻微的开合
2. **talk.png** —— 4 帧,8fps,壳打开幅度变大,露出里面的珍珠光泽,作为"说话中"的反馈

交付文件:
- `idle.png` = 32×2 = 64px 宽,24px 高
- `talk.png` = 32×4 = 128px 宽,24px 高

## 背景知识

- 珍珠贝 *Pinctada radiata* 在阿拉伯湾具重要经济文化意义,考古贝丘含大量珍珠贝壳
- 珍珠爷爷住在「珍珠滩」,亚成年期解锁,角色功能是财商核心,有四句核心台词:「不是所有东西都一样值钱」「好东西要等」「换东西要两边都愿意」「有些东西不换」

## 拿到图之后怎么处理

1. 检查透明背景、没有多余白边或阴影
2. 确认帧宽严格等于 32px 的整数倍
3. 两个文件改名为 `idle.png` / `talk.png`,放进 `public/assets/npc/pearl_grandpa/` 文件夹
4. 在浏览器里确认它明显比砗磲奶奶朴素、小一圈,两者不会认混
