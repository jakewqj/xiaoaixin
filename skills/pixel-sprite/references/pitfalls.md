# 踩坑清单(实测验证)

## 环境 / Shell

1. PowerShell 里多行 `\` 续行必报错("一元运算符 -- 后面缺少表达式") -> 所有命令用 `cmd /c "..."` 单行写完。
2. 长 inline `node -e "..."` 会报"线程未能启动" -> 一律写 .mjs 脚本文件再运行。
3. apply_patch 新建文件: Add File 后内容每行都要 `+` 前缀, 否则报 invalid hunk。
4. 沙箱内 Start-Process 起的 dev server 会随命令结束被回收 -> 用 require_escalated 提权启动。
5. 沙箱内访问 localhost 返回 000/拒绝 -> 提权验证; vite 可能只绑 IPv6, `http://localhost:端口` 能通而 `http://127.0.0.1` 不通, 别误判成服务器没起来。
6. `python` 在本机沙箱常启动失败 -> 全部用 node。
7. 仓库已有文件含 UTF-8 中文, 控制台显示乱码是正常现象, 不要"修复"编码; 新文件注释可用中文, 但 console.log 保持 ASCII 防乱码。

## 图像 / 预览

8. view_image 看宽图(如 768x64 以上)会被缩略到模糊 -> 调试图按单帧/单姿势输出原尺寸或 2x 小图, 红色锚点 3x3 标记直接画在图上。
9. AI 生图(DALL-E、网页端 Gemini/ChatGPT)无法保证帧宽倍数、固定色号、锚点坐标、<=16 色、无抗锯齿 -> 规格精确时必须手写生成器, 不要浪费时间试。
10. 透明背景用 verify-sheet.mjs 的 alpha>0 像素统计确认, 不要在白色背景上目测。

## 规格 / 协作

11. 锚点以游戏配置文件(如 pet.json)为准, 不以 prompt 里的表格为准——先读配置再定坐标。
12. 游戏内热区/泡泡位置小偏差: 改配置 JSON 的锚点值, 不重新生成图。
13. 帧像素数逐帧应大致相等且略有变化: 完全相等说明没动起来, 差异过大说明有帧缺损。
